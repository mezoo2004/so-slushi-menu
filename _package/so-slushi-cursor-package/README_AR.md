# حزمة منيو سو سلوشي - جاهزة لكورسر

هذه الحزمة مرتبة لتطبيق منيو **SO SLUSHI / سو سلوشي** بنفس منطق وتجربة مشروع **Cupid Burger / Copid-menu** السابق، مع فصل هوية سو سلوشي السوداء والذهبية عن هوية كوبيد.

## ترتيب الاعتماد
1. **الأسعار الحالية التي أرسلها المستخدم في المحادثة هي المرجع النهائي للأسعار.**
2. المنيو القديم استُخدم لمعرفة أسماء المنتجات القديمة وأسماء الصوصات فقط، وليس للاعتماد على أسعاره القديمة.
3. الصور الجديدة طابقتها بصرياً مع المنتجات. عند عدم وجود تطابق موثوق لم أربط صورة خاطئة.

## أهم ما تم تنظيفه
- تم تصفية صور مكررة/إعادة تصوير لنفس المنتج.
- تم اختيار صورة رئيسية واحدة للأضلاع وصورة رئيسية واحدة للبريسكت فرايز وغيرها.
- صورة السلايدر المكس استُخدمت أيضاً لإنشاء Crop مستقل لسلايدر الدجاج وسلايدر اللحم.
- صور الصوصات الثمانية محفوظة في `assets/sauces-reference/` بأسماء عامة؛ **لا تربطها تلقائياً بأسماء الصوصات** لأن المصدر لا يحدد أي صورة لأي صوص.
- `لحم كيتو` له سعر مؤكد لكن لا توجد صورة جديدة يمكن مطابقتها بثقة، لذلك `image` = null.
- صور الستيك (تندرلوين/ريب آي) نسختان معدلتان من **نفس مصدر التصوير**؛ لذلك تم تمييز الثقة كـ medium وعدم إخفاء هذه المعلومة.

## الملفات
- `CURSOR_PROMPT.md` : البرومبت النهائي الذي ترسله لكورسر.
- `menu-data.json` : مصدر البيانات الرئيسي للمنيو، عربي/إنجليزي وأسعار وصور.
- `image-audit.csv` : تدقيق كامل لكل صورة أصلية: مستخدمة / مكررة / مستبعدة / مرجع فقط.
- `assets/menu-final/` : الصور النهائية فقط بأسماء واضحة مناسبة للكود.
- `assets/sauces-reference/` : صور الصوصات بدون ربط اسم خاطئ.
- `assets/brand/` : مرجع الهوية واللوجو المأخوذ من صورة التيشيرت.

## ملاحظات تنفيذ مهمة
- لا تستخدم أسعار المنيو القديم.
- لا تخترع وصفاً أو سعرات أو حساسية أو مكونات غير موجودة في البيانات.
- لا تعيد الصور المستبعدة لمجرد زيادة عدد الكروت.
- إذا كان مشروع كوبيد الحالي يحتوي حقول calories/allergens/descriptions، اجعلها فارغة أو اخفها عندما لا تتوفر بيانات، ولا تخترع قيم.
